Register

All Accounts

Consolidated view

What it is

All Accounts (sidebar → All Accounts) shows one transaction table for every active account. It does not store separate copies—each row still belongs to its account, and edits sync to that account’s register immediately.

Columns and sorting

Date, Account (opens account detail), Payee, Category, Outflow, and Inflow. Sort any column; search payee, category, account, memo, or amount.

Filters and bulk actions

  • Accounts (one or many), date presets, category, payee, type (income/expense/transfer), status (cleared/uncleared/reconciled/flagged)
  • Recent ranges: 7 days through all transactions
  • Bulk categorize, clear, reconcile, flag, delete; Select all (filtered) for large sets

Large lists use pagination and virtual scrolling. CSV import picks an account first—imports always attach to that account.

Not on this screen

Reconciliation, bank linking, account settings, and balance adjustments stay on Account Details or Linked Banks.

Quick edits

  • Click payee to edit inline
  • Use category dropdown on a row
  • Use ✏️ for date, amount, memo, cleared, and flag

Add transaction

Choose account, date, payee, category, and amount—the new row is saved on that account only.

Prosperity Map

Smart Assign

Ready to Assign

What Smart Assign does

Smart Assign is a one-click action on the Prosperity Map (🧠 Smart Assign). It takes your unassigned cash—shown as Ready to Assign—and spreads it across categories that still need funding for the month you are viewing.

Ready to Assign is one shared pool across every budget month: cash in your on-budget accounts minus the sum of Assigned in all months (past, current, and future). Assigning in July or August reduces the same Ready to Assign you see in June. If Ready to Assign is zero or negative, Smart Assign cannot run.

Reserved in Future shows how much of that assigned total lives in months after the current calendar month—helpful when Ready to Assign looks low because you already budgeted ahead.

How priorities are determined

Smart Assign only considers active (non-archived) categories that need money this month. A category is eligible when either:

  • Its Available balance is negative (overspent), or
  • It has a Goal Target and still needs funds to reach that target (gap between target and Available).

Among eligible categories, Smart Assign sets priority by Goal Target size (the budget target column in the Prosperity Map table):

  • Smallest Goal Target first — categories with the lowest target amount are funded before larger ones.
  • If two categories share the same Goal Target, they are ordered alphabetically by category name.

How funds are distributed

After sorting smallest-to-largest Goal Target, Smart Assign walks the list in order:

  1. Start with the category that has the smallest Goal Target.
  2. Assign up to the amount that category still needs, but never more than the remaining Ready to Assign pool.
  3. Move to the category with the next smallest Goal Target and repeat.
  4. Continue until either every eligible category is fully funded for its need, or all available Ready to Assign money has been distributed.

If a category needs more than what is left in the pool, it receives only the remainder; later categories may receive nothing once the pool is empty.

Confirm before saving

Smart Assign shows a preview listing each category and amount. After you confirm, amounts are saved to the selected budget month (Assigned column) and the Prosperity Map refreshes.

Quick reference

  • Where: Prosperity Map toolbar → 🧠 Smart Assign
  • Source of funds: Ready to Assign
  • Sort order: Goal Target ascending (smallest first)
  • Per category: min(amount still needed, remaining pool)
  • Stops when: pool is empty or list is finished

Related actions

  • Fund Underfunded — uses a different urgency order (overspent and goal types), not smallest-target-first. Button total includes overspending plus goal gaps.
  • Global RTA — every assignment in any month draws from the same Ready to Assign; future-month assignments reserve cash immediately.
  • Last Month / Average — match prior assigned amounts or average spending instead of goal targets.
